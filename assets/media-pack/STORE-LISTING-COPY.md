## Name

Speed Dial

## Short description

Customize Chrome's new tab with site groups, tile images, quick search, and local backup and restore.

## Detailed description

Speed Dial turns a new Chrome tab into an organized home for the sites you use. Group links by purpose, choose their colors and tile images, and switch between a compact Tabs layout and an expanded Sections layout.

- Add sites from the new tab page, toolbar button, or right-click menu.
- Arrange tiles and groups by dragging them.
- Use Chrome's cached site icons, your uploaded images, linked images, or simple letter tiles.
- Filter saved sites from the search box or send a search to your default engine.
- Choose light, dark, or automatic theme, tile size, and an optional background image.
- Export a JSON backup and restore your setup on another browser or computer.

Groups, tiles, settings, uploaded images, and the background are stored in Chrome's local extension storage. If **Fetch missing site icons** is enabled and Chrome has no icon for a site, Speed Dial can ask Google's favicon service for that site's origin. You can turn this lookup off in Settings. A linked tile image loads from the image host you specify. Searching the web uses your default search engine.

Chrome 116 or newer is required. Speed Dial replaces Chrome's new tab page after installation.
